## 任務（Strata repo，`/home/tommy/repo/Strata`，分支 `feat/dashboard-baseurl`）

使用者要求：web dashboard 可以用 `/ui` 而唔係 `/`。最終設計（使用者逐步收窄）：
- **可選** run config key `"dashboard": "/ui"`（top-level，唔係 args 入面）或 `serve/server.py --dashboard /ui`；冇寫／`"/"` → 全部照舊喺 root（向後兼容）。
- **只搬網頁自己嘅嘢**：page、`/web/*`（CSS/JS/sprite/monitor.js）、`/fonts/*`、`/api-monitor`。`/` 之後回 404。
- **API 唔喺 scope**：`/v1/*`、`/health`、`/metrics`、`/status`、`/slots`、`/mcp` 等照舊喺 root，client base URL 唔使改。因為 page 全部用相對 URL（上游 #82 嘅設計），由 `/ui/` 開時佢自己嘅 call 會到 `/ui/health` 等 → `_route()` 兩種寫法都接受。
- `/ui`（冇尾斜線）→ 301 `/ui/`（保留 `?q=`）。非法 path 喺 load model 之前 `ap.error()` 停低。
