## 已完成（repo `/home/tommy/repo/Strata`，branch `feat/dashboard-baseurl`）

**功能**：run config 加 `"dashboard": "/ui"` 或 `serve/server.py --dashboard /ui`，將**網頁本身同佢自己嘅檔案**搬到該路徑：
- `/ui/` → 傾計頁（`serve/web/index.html`）；`/ui/web/*`、`/ui/fonts/*`、`/ui/api-monitor` 跟住搬
- `/`、`/web/*`、`/fonts/*`、`/api-monitor` → 而家係 404（**用戶而家要求改做 301 去 `/ui/`**）
- **API 完全唔郁**：`/v1/*`、`/health`、`/metrics`、`/status`、`/slots`、`/mcp`、`/props` 照舊喺 root；同時 `/ui/v1/*`、`/ui/health` 呢類（網頁用相對 URL #82 產生嘅）都 work
- 預設（冇寫或 `"/"`）行為零改變；`dashboard_of()` 驗證：必須 `/` 開頭、字母/數字/`-`/`_`、長度 ≤60、第一位唔可以係 `SERVED_PATHS` 嘅名（`/web`、`/v1`、`/fonts`、`/api`、`/metrics`、`/health`、`/status`、`/slots`、`/models`、`/props`、`/mcp`、`/config`、`/settings`、`/unload`、`/load`、`/api-monitor`），錯就喺 load 模型之前 `ap.error(...)`
- `APP_PATHS = ("", "web", "fonts", "api-monitor")`：有 dashboard 時呢幾個 first segment 必須喺 prefix 下面
- `/ui`（冇尾斜線）→ 301 → `/ui/`，保留 `?q=`

**关键函数**：`serve/server.py` `Service.dashboard`（預設 `""`）；handler 入面 `_route()`（prefix 剝走，返 None 代表唔係我哋嘅 page path）同 `_not_our_app()`（301 或 404）；`_cors()` 用 `(self._route() or "").startswith("/v1/")`；`do_GET`/`do_POST` 開頭 `path = self._route(); if path is None: self._not_our_app(); return`。`main()` 有 `dashboard` 局部變數、`svc.dashboard = dashboard`、`page = f"http://{here}:{a.port}{dashboard or ''}/"`（ready print 嘅 API 仍然 `/v1`，`from other devices` print 頁用 prefix、API 寫 `/v1`）、`webbrowser.open(page)`。

**其他檔案**：`serve/web/monitor.html` 同 `serve/web/monitor.js` 改做**相對 URL**（`web/tokens.css`、`web/monitor.js`、`api/requests`、`v1/status`、`load`/`unload`）；`sycl/serve/server_intel.py` 改復用 `self._route()`，`path == ""` 先 serve index 頁，None 時 `super().do_GET()/do_POST()`。
